# TTC AutoCAD Simulator

Browser-based UX and workflow simulator for TTC CAD Engineering Tools.

Purpose:

Explore and validate the proposed AutoCAD engineering tool workflows before implementing the real AutoCAD 2023 C# plugin.

Development strategy:

Concept
→ UX Simulation
→ Feature Validation
→ UX Decision
→ Functional Freeze
→ Technical Specification
→ Real AutoCAD Plugin Development
